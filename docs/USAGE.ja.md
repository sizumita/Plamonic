# Plamonic の使い方

Plamonic のインストールから、使い方、設定、うまく動かないときの確かめ方までをまとめたガイドです。
概要と動作環境は [README](../README.ja.md) を見てください。

## インストール

1. [最新のリリース](https://github.com/sizumita/Plamonic/releases/latest)から `Plamonic.dmg` をダウンロードして開き、`Plamonic.app` を「アプリケーション」フォルダにドラッグします。
2. 「アプリケーション」フォルダの Plamonic を開きます。配布しているアプリは Developer ID で署名し、Apple の公証を受けているので、そのまま開けます。
3. メニューバーに吹き出しのアイコンが出ます。Dock には出ません。

## はじめて起動したとき

1. **アクセシビリティの許可**
   案内のウインドウが開きます。「システム設定を開く」を押し、「プライバシーとセキュリティ」>「アクセシビリティ」で Plamonic をオンにしてください。
   許可されると、アプリを再起動しなくても読み取りが始まります。モデルがあれば、そのまま翻訳も始まります。
2. **翻訳モデルのダウンロード**
   モデルがまだないときは、翻訳モデルの 2B と段階翻訳の下書き用の 0.8B（合わせて約 3.4 GB）をダウンロードするボタンが出ます（段階翻訳もオンになります）。どちらかのダウンロードが終わると、そのモデルで翻訳が始まります。
   ほかのサイズは「設定」>「モデル」から選べます。
   モデルは Preferred Networks が [PLaMo Community License](https://plamo.preferredai.jp/info/plamo-community-license) のもとで公開しています。使う前にライセンスを確認してください。商用で利用する場合は Preferred Networks への登録が必要です。
   モデルは `~/Library/Application Support/Plamonic/Models/pfnet/<リポジトリ名>/` に保存され、ダウンロードが終わると `.complete` という印のファイルが置かれます。
   ダウンロード中は同じ場所の `.<リポジトリ名>.partial` にファイルを集めます。通信が一時的に切れたときは、ファイルごとに数回やり直します。
   それでも失敗したときは済んだファイルを残し、次にダウンロードするとその続きから始めます（「モデル」に「続きからダウンロード」と表示されます）。
   キャンセルするか「削除」を押すと、途中までのファイルも消えます。`.complete` はすべてのファイルがそろって確認できたときにだけ置きます。
   モデルのファイルが壊れていたり `config.json` と重みの形が合わなかったりすると、アプリは落ちずに「モデルファイルを読み込めません」と表示します。
3. **見た目をなじませる（任意）**
   「画面収録を許可…」を押すと、訳文の背景色と文字色を元のアプリの画面から測るようになります。
   取り込んだ画面は色を測るためだけに Mac の中で使い、保存も送信もしません。許可しなくても翻訳はできます（訳文はテーマの色で表示します）。
   許可したあと、反映に Plamonic の再起動が必要なことがあります。

## 使い方

メニューバーの吹き出しのアイコンから操作します。

- **翻訳を有効にする**: すべての翻訳をオン・オフします。既定のホットキーは ⌃⌥T です。
- **<前面のアプリ> の動作**: 今使っているアプリを「オフ / 自動 / 手動」に切り替えます。
  - 自動: 画面が変わるたびに翻訳し直します。
  - 手動: 「今すぐ翻訳」を押したときだけ翻訳します。訳文は、画面の内容が変わるか、Esc を押すか、もう一度ホットキーを押すまで表示されたままです。
- **今すぐ翻訳**: 既定のホットキーは ⌃⌥R です。自動モードのアプリでは、すぐに読み直して、失敗した翻訳をやり直します。
- **原文を見る**: ⌥（Option）だけを押している間、訳文が消えて原文が見えます。
- **ポインタを置いて原文を見る**: 訳文の上でポインタを少し（既定 0.4 秒）止めると、訳文はそのままで、原文を吹き出しで表示します。ポインタを離すと吹き出しは消えます。スクロールすると吹き出しは閉じ、スクロールで訳文がポインタの下に来ただけでは出ません。「表示」の「ポインタとリンク」で、その場で原文を見せる（その訳文だけが消えて下の原文が見える）・何もしない、にも変えられます。
- **訳文の全文を見る**: 長すぎて末尾を「…」にした訳文は、マウスを少し置くと全文（と原文）を吹き出しで表示します。
- **リンク**: 訳文の中のリンクは、リンクの部分だけをリンクの色で表示します（原文に下線があれば下線も付けます）。押すと原文のリンクと同じように開きます。
  - アプリ自身にリンクを押させます。押せないときだけ URL を開きます（http / https / mailto だけ）。ターミナルの URL はブラウザで開きます。
  - 訳文の下に隠れている原文のリンクは押されません。そこをクリックすると、その訳文の原文が見えます（見えている間は原文のリンクを押せます）。原文が見えた直後のクリック（ダブルクリックの 2 回目など）は何もしません。それ以外の場所のクリックは、ふだんどおりアプリに届きます。ただし、ネイティブアプリのテキスト表示の中のリンクは、訳文の下に隠れていても押されることがあります。
  - 訳文のリンクはボタンを離したときに開きます。押したまま外へずらすと取り消せます。
  - 訳文のリンクの上では、カーソルが指の形になり、リンクに下線が出ます（もともと下線のあるリンクは、色が少し強くなります。明るい背景では濃く、暗い背景では明るくなります）。
  - 訳文のリンクを右クリック（または control クリック）すると、原文のリンクを右クリックしたときと同じ、そのアプリのメニュー（「リンクのアドレスをコピー」など）が出ます。メニューの位置はアプリが決めます（Chrome などでは原文のリンクの中央）。アプリがメニューを出せないとき（ターミナルの URL など）は、Plamonic の小さなメニュー（「リンクを開く」「リンクのアドレスをコピー」「原文を表示」）がクリックした位置に出ます。
  - 訳文の下に隠れた原文のリンクを右クリックすると、ふつうのクリックと同じで原文が見えます。そのまま原文のリンクを右クリックできます。それ以外の場所の右クリックは、ふだんどおりアプリに届きます。
  - 「表示」の「訳文のリンクを押せるようにする」をオフにすると、リンクの色付けもせず、訳文の上のクリックはすべてアプリに届きます。
- スクロール中やウインドウを動かしている間は訳文（選択したテキストの吹き出しも）を隠し、止まってから約 0.15 秒後に読み直して表示し直します。
- 手動モードのアプリでは、モデルを「今すぐ翻訳」を押したときに読み込みます。手動モードのアプリに切り替えただけではモデルをメモリに読み込みません。

生成中の訳文は少し薄く表示します。段階翻訳の下書きには、文末に小さな点が付きます。翻訳モデルの訳に差し替わると点は消えます。点は「表示」で消せます。
新しい文章が一度にたくさん現れて仕上げを止めている間は、メニューに「仕上げを一時停止中（新しい文章が多いため）」と表示します。

### パスワードの入力中

パスワードを入力している間は、ほかのアプリの文章も画面も読み取りません（「一般」の「パスワード入力中は読み取らない」。既定はオン）。

- **止めるとき**: パスワード欄に入力しているとき（macOS のセキュア入力がオンのとき、または読み取っているアプリでパスワード欄にフォーカスがあるとき）と、ロック解除や管理者のパスワードなど、システムのパスワード画面が出ているとき。
- **止めている間**: どのアプリも読み取らず、背景色を測るための画面の取り込みもしません。「今すぐ翻訳」も何もしません。表示中の訳文はそのまま残ります。メニューに「パスワード入力中のため、読み取りを止めています（アプリ名）」と表示します。
- **終わったら**: すぐにすべてのアプリを読み直します。
- **ターミナル**（Terminal / iTerm2）: `Password:` や `[sudo] password for …:` のようにパスワードを待っているウインドウだけ、読み取りを止めます（メニューに「<アプリ名> がパスワードを待っているため、このウインドウの読み取りを止めています」）。画面に何か出力されると読み直します。入力の代わりに `*` などの印を出すプロンプト（sudo の pwfeedback など）でも、印の入力では読み直しません（ターミナルが入力位置を教えないときは、2 秒に 1 回まで読み直します）。印は訳文にもキャッシュにも入りません。読み取っているターミナルが前面にあり、その画面にフォーカスがあるときは、ターミナルの「セキュアキーボード入力」では止めません（オンのままにしていることが多く、ターミナルはパスワードを表示しないため）。

## 設定

「設定…」で開くウインドウには次の項目があります。

| 画面 | 内容 |
| --- | --- |
| 一般 | 翻訳のオン・オフ、ログイン時に起動、未登録アプリの動作と範囲、アプリを切り替えた後も翻訳を続けるか、パスワード入力中は読み取らない（既定オン）、アップデート（自動で確認する、ベータ版を受け取る、今すぐ確認） |
| 翻訳 | 翻訳先の言語（53 言語とやさしい日本語）、翻訳元の言語、文体（常体 / 敬体）、翻訳先と同じ言語の文章を訳すか、途中経過を表示するか |
| モデル | 翻訳モデルの選択、段階翻訳（オン・オフと下書きモデル）、混雑時の一時停止（しきい値と再開までの時間）、ダウンロード・削除、メモリからの解放、ライセンス |
| アプリ | アプリごとの設定。動作モード、読み取る範囲、抽出ルール、粒度、文脈、用語集、会話履歴、段階翻訳（全体の設定に従う / 使う / 使わない）など。「要素を調べる」で、マウスの下の要素から抽出ルールを作れます |
| 用語集 | すべてのアプリに共通の用語集。読み込みと書き出しもできます。訳語が空の用語は使いません（読み込むときも飛ばします） |
| 表示 | 置き換え / ホバーの切り替え、原文になじませる（原文の見た目に合わせる・背景色を画面から取る、画面収録の許可）、プレビュー、テーマ、背景の不透明度、文字サイズの範囲、下書きの印、原文を見るためのキー、ポインタとリンク（ポインタを置いたとき: その場で / 吹き出し / 何もしない、待ち時間 0.1〜1.5 秒、訳文のリンクを押せるようにする）、スクロール中に隠すか |
| ホットキー | 翻訳のオン・オフ、今すぐ翻訳 |
| 詳細 | 走査の間隔、上限、キャッシュ、モデルを解放するまでの時間、設定ファイル |

設定は `~/Library/Application Support/Plamonic/settings.json` に保存されます。文字を入力する欄は、Return を押したとき、ほかの欄やアプリに移ったとき、設定ウインドウを閉じたときに反映されます。
ファイルが壊れていた場合は `settings.corrupt-<日時>.json` に退避し、読めた部分だけで起動します。項目が欠けているだけなら、その項目を既定値にして残りはそのまま読みます。
ファイルが読めない（権限がないなど）ときは、`settings.json.bak` か既定値で起動し、その回は設定ファイルを書き換えません。「詳細」にその旨を表示します。
訳文のキャッシュは `translation-cache.json` に保存されます。ここにはほかのアプリの文章が入るので、権限 0600 で書き込みます。書き込みは多くても 30 秒に 1 回で、終了時に残りを書きます。
「詳細」でディスクへの保存をやめると、このファイルはすぐに削除されます（保存をやめた状態で起動したときも削除します）。
キャッシュの件数は 1,000〜50,000 件で設定できます。画面に出ている訳文がそれより多いときは、表示中のものを消さないように一時的に上限を広げます。

### 読み取る範囲

| 範囲 | 内容 |
| --- | --- |
| ウインドウ全体 | 前面のウインドウにあるすべての文章 |
| ルールで指定した部分 | アプリ別の抽出ルールに合う部分だけ（メッセージ本文など） |
| フォーカス中の要素 | キーボードのフォーカスがある要素の中。訳文はその要素の中に収めます |
| マウスの下のブロック | ポインタの下の段落やメッセージ 1 つ。行間や余白の上では、10pt 以内にある文章だけを訳します。訳文はそのブロックの中に収め、同じブロックのほかの段落には重ねません |
| 選択したテキスト | 選択した文章の訳を吹き出しで表示 |

## 対応アプリ

主なアプリにはあらかじめプリセット（抽出ルール）を用意しています。

| アプリ | 方式 | 状態 |
| --- | --- | --- |
| Slack | メッセージ本文（`p-rich_text_section` / `list` / `quote`）。コードブロック、送信者、時刻は除外 | 動作確認済み |
| Discord | メッセージ本文（`messageContent_`）と埋め込みの説明。返信のプレビュー、「(編集済)」、コードは除外 | 動作確認済み |
| Claude（Claude Code タブ） | チャット欄（`epitaxy-chat-panel-body`）の中のメッセージ行（`group/message-row`）。ツール実行の表示は除外。チャット欄がない画面（チャットタブ）ではウインドウ全体からメッセージを探します（未検証） | 動作確認済み |
| OpenCode（デスクトップ版） | 本文領域（`scroll-view__viewport`）の段落。ツール実行と固定ヘッダは除外 | 動作確認済み |
| Codex（デスクトップ版） | Web チャット向けの汎用ルール | 未検証 |
| DeepSeek Harness | Web チャット向けの汎用ルール | 未検証 |
| ターミナル（Terminal.app） | 見えている行だけを読み、折り返しを段落に戻し、罫線・スピナー・プロンプト・ツール呼び出しの行は除外。Claude Code / Codex / OpenCode の CLI 向け | 動作確認済み |
| iTerm2 | ターミナルと同じ方式 | 未検証 |
| Ghostty | 文字の位置（`AXBoundsForRange`）を公開していないため、今は訳せません | 非対応 |

Slack、Discord、Claude などの Electron アプリには、起動後はじめて読み取るときに `AXManualAccessibility` を設定します。設定してから Web 部分の構造が揃うまで数秒かかります。
Plamonic が自分でオンにした `AXManualAccessibility` / `AXEnhancedUserInterface` は、そのアプリの動作を「オフ」にしたとき（翻訳全体をオフにしたときも）、翻訳を止めたとき、Plamonic を終了したときに元に戻します。もともとオンだった場合（VoiceOver など）はそのままにします。
アプリ別設定でこれらのスイッチを切った場合は、次にそのアプリを読み取るときに戻します。
抽出ルールでコンテナを指定していても、ウインドウにコンテナが見つからず項目が指定されているときは、ウインドウ全体から項目を探します。
プリセットのないアプリは「一般」の「未登録のアプリ」の設定で動きます。既定は「手動」で、範囲は「ウインドウ全体」です。

## 段階翻訳（下書き → 仕上げ）

段階翻訳は「設定」>「モデル」でオン・オフできる機能です。オフのときは、選んだ**翻訳モデル**（既定 2B）だけで 1 回訳します。
オンのときは次のように動きます。

1. 画面に新しい文章が現れると、まず**下書きモデル**（既定 0.8B）で訳してすぐに表示します。
2. 下書きがすべて終わったら、**翻訳モデル**で上から順に訳し直し、終わったものから差し替えます。
3. 推論は 1 本ずつ順番に行います。優先度は次の順です。
   1. 手動の翻訳
   2. まだ訳のない文章の下書き
   3. 下書きのない文章の仕上げ
   4. 下書きの差し替え

   前面のアプリのウインドウを先に処理します。画面から消えた文章の翻訳は取り消します。
   長い文章を翻訳モデルで訳し直している途中に新しい文章が現れると、区切りのよいところで先に新しい文章の下書きを出し、そのあと続きから訳し直します。
4. 訳文は「原文・翻訳元・翻訳先の言語・文体・文脈・用語集・モデル」ごとにキャッシュするので、同じ文章は次から即座に表示されます。翻訳元の言語を変えると訳し直します。

- 下書きモデルには翻訳モデルより小さいサイズだけを選べます。翻訳モデルが最小（0.8B）のときは 1 段で訳します。
- アプリごとに「全体の設定に従う / 使う / 使わない」を選べます（「設定」>「アプリ」の「翻訳」）。たとえばターミナルだけ段階翻訳を使わない、といった使い分けができます。下書きモデルと混雑時の一時停止の設定は全体で共通です。
- 下書きモデルが入っていないときは翻訳モデルだけで、翻訳モデルが入っていないときは下書きモデルだけで訳し、メニューにその旨を表示します。

### 混雑時の一時停止

スクロールやメッセージの連投で新しい文章が一度にたくさん現れると、翻訳モデルが訳し直している間、新しい文章の下書きが待たされます。
そこで、新しい文章が流れ込んでいる間は仕上げを止めて、下書きだけを進めます（「モデル」の「混雑時の一時停止」。既定はオン）。

- **止める**: そのアプリで、下書きを待っている文章が一度にしきい値（既定 8 件）以上あるか、2 秒以内に新しく現れた文章がしきい値以上のとき。
  訳し直しの途中だったものはすぐに止め、長い文章なら済んだ部分を覚えておきます。止めている間の下書きは、新しく現れた文章から順に作ります（流れていく古い文章ほど先に画面から消えるため）。伸びている途中の段落は最後に回します。
- **再開する**: 新しい文章がしばらく（既定 1.5 秒）ほとんど来なくなり、画面上の文章すべてに下書きが付いたとき。画面にある文章を上から順に仕上げます。
- 止めるのは、文章が流れ込んでいるアプリだけです。ほかのアプリや、段階翻訳を使っていないアプリの翻訳はそのまま進みます。メニューには前面のアプリの状態を表示します。
- 生成中の返信の段落が伸びていく、段落の上が画面の外に切れる、といった「その場の変化」は新しい文章と数えません。返信が流れてくるだけでは止まりません。
- ログが流れ続けるターミナルなどでは、流れが続く限り仕上げは止まったままです。見えている文章は下書きで読めます。

## 原文になじませる表示

訳文は「上に貼った札」ではなく、アプリ自身が表示しているように見せます（「表示」の「原文になじませる」）。

- **原文の見た目に合わせる**（既定オン）: アプリが教えてくれる原文の文字の大きさ・行間・文字色で、原文の 1 行目の位置から書きます。ターミナルでは等幅の文字を使います。背景は原文の行だけを覆い、枠線や影は付けません。
  - 訳文が長いときは、①下の空き（次の文章の手前まで）に行を足す、②原文の 85% まで縮める、③それでも入らなければ末尾を「…」にする、の順に収めます。「…」にした訳文は、マウスを少し置くと全文を吹き出しで表示します（原文を見るキーは原文を見せます）。
  - 段落が行の途中で 2 つに分かれていても（リストの項目の途中にリンクがあるときなど）、前半と後半は同じ行を左右に分け合い、重なりません。
  - ほかの段落はもちろん、訳さない名前・時刻・ボタン・コードブロック・入力欄・ターミナルの枠線やプロンプト、翻訳先と同じ言語で訳さなかった文章にも重ねません。訳しても原文と同じになった文章（コードや名前など）も、重ねずに原文のまま見せます。
  - 原文の大きさが分からないアプリでは、「文字サイズの範囲」の中で枠に合わせます。
- **背景色を画面から取る**（既定オン）: 訳す対象のウインドウの画素から、項目ごとに背景色と文字色を測ります。測るのは、まだ測ったことのない場所に文章が現れたときです。スクロールや生成中の文章では前に測った場所の色をそのまま使い、測り直しは 5 秒に 1 回までにします。スクロール中は測りません。
  - **画面収録の許可**が必要です（任意）。取り込んだ画面は色を測るためだけに Mac の中で使い、保存も送信もしません。測った色以外は何も残りません。
  - 許可がないときや半透明の背景のときは、原文の文字色から明るい背景か暗い背景かを決めて、テーマの色を使います。
  - ターミナル（Terminal.app）は文字色を教えないので、許可がないときはテーマ（「システムに合わせる」ならシステムの外観）の色になります。ターミナルの配色と合わないときは、画面収録を許可するか、「表示」の「テーマ」を選んでください。
  - 新しい文章は、色を測り終えるまで近くの文章の色で表示し、測れたら滑らかに切り替えます。

## アップデート

Plamonic は新しい版が出ていないかを自分で確かめます。設定は「設定」>「一般」の「アップデート」にあります。

- **自動でアップデートを確認する**（既定オン）: 1 日に 1 回確認します。新しい版が見つかってもウインドウは出さず、メニューに「アップデートがあります（<バージョン>）」と表示します。押すとアップデートのウインドウが開き、そこからインストールできます。
- **今すぐ確認**（メニューの「アップデートを確認…」も同じ）: すぐに確認して、結果をウインドウで表示します。
- **ベータ版を受け取る**: main ブランチが変わるたびに作るベータ版（`0.2.0-beta.3` のような版）も受け取ります。オンのときも、使っている版より新しい正式版が出れば、正式版にアップデートします。ベータ版を入れると、この設定はオンになります。
  - ベータ版を使っているときにオフにしても、古い正式版に戻すことはしません。使っているベータ版より新しい正式版が出たときに、その正式版にアップデートします。
  - ベータ版は [beta のプレリリース](https://github.com/sizumita/Plamonic/releases/tag/beta)（`Plamonic-Beta.dmg`）から直接入れることもできます。正式版と同じ Plamonic で、設定もモデルもそのまま使います。
- ダウンロードしたアップデートは、署名を確かめてから入れ替えます。アップデートしても、アクセシビリティなどの許可はそのまま残ります。
- 確認するときは GitHub のリリースにある `appcast.xml` を読むだけで、使い方や Mac の情報は送りません。
- ソースからビルドしたアプリは自動でアップデートしません（「アップデート」に「このビルドは自動アップデートしません（ソースからビルドしたため）」と表示します）。

## うまく動かないとき

- **何も訳されない**
  - メニューで前面のアプリの動作が「オフ」になっていないか確認してください。
  - 翻訳先と同じ言語の文章は、既定では訳しません。日本語のチャットは日本語のまま残ります。訳したい場合は「翻訳」の「翻訳先と同じ言語のテキスト」を変更してください。
  - Electron アプリでは、起動して最初の数秒は文章が読み取れないことがあります。
  - 応答しないアプリは、読み取りの間隔を最大 4 秒まで空けます。「今すぐ翻訳」を押すとすぐに読み直します。
- **アクセシビリティを許可したのに訳されない**
  「システム設定」>「プライバシーとセキュリティ」>「アクセシビリティ」で Plamonic をいったん削除（−）して、追加し直してください。
  ソースからビルドしたアプリは、アドホック署名だとビルドするたびに許可が外れます。[DEVELOPMENT.md](DEVELOPMENT.md#signing-local-builds) のとおりに署名の設定をしてください。
- **訳文の位置がずれる、関係ない部分まで訳される**
  「設定」>「アプリ」で範囲を「ルールで指定した部分」にし、「要素を調べる」で本文の要素の DOM クラスを確かめて、ルールを調整してください。
- **メモリを多く使う**
  - 「詳細」でモデルを解放するまでの時間を短くしてください。
  - 「モデル」の「モデルをメモリから解放」でもすぐに解放できます。
  - 翻訳モデルを小さくするか、段階翻訳をオフにする方法もあります（下書きモデルの分のメモリが要らなくなります）。
- **訳文のリンクが押せない、リンクの色にならない**
  訳文の中でリンクの位置が分からなかったときは、リンクにしません。リンクがあった場所をクリックすると原文がその場で見えるので、原文のリンクを押してください（「ポインタを置いたとき」が「その場で」なら、ポインタを置くだけでも見えます）。「表示」の「訳文のリンクを押せるようにする」がオンになっているかも確認してください（表示スタイルが「原文に重ねる」のときだけ使います）。
- **訳文のリンクの上でカーソルが指の形にならない**
  Plamonic は前面に出ないまま、macOS の公開されていない仕組みでカーソルを変えています。その仕組みが使えないときは指の形になりません（ログに `Background cursor unavailable` と出ます）。リンクの上で出る下線（もともと下線のあるリンクでは色の変化）はカーソルと関係なく出るので、それを目印にしてください。下のアプリがすぐに自分のカーソルに戻して、一瞬だけ元の形になることもあります。
- **訳文のリンクを右クリックしてもメニューが出ない**
  アプリが時間内に答えなかったときは、メニューを出しません（あとでアプリのメニューが出ることがあり、二重にしないため）。もう一度右クリックしてください（同じリンクの 0.5 秒以内の右クリックは無視します）。訳文の下に隠れた原文のリンクを右クリックすると、原文が見えるので、原文のリンクを直接右クリックすることもできます。
- **訳文の色が元のアプリと違う**
  「表示」の「背景色を画面から取る」がオンで、「画面収録の許可」が「許可されています」になっているか確認してください。許可した直後は Plamonic の再起動が必要なことがあります。許可しない場合は、「テーマ」をアプリの配色（明るい / 暗い）に合わせてください。
- **仕上げの訳に差し替わらない**
  メニューに「仕上げを一時停止中」と出ているときは、前面のアプリに新しい文章が流れ込んでいる間です。流れが止まると再開します。アプリ別設定で段階翻訳を「使わない」にしていないかも確認してください。
- **読み取りが止まったまま**
  メニューに「パスワード入力中のため、読み取りを止めています（アプリ名）」と出ている間は、どのアプリも読み取りません。括弧の中は、パスワードの入力を受けているアプリです。
  - 括弧のない「パスワード入力中のため、読み取りを止めています」は、画面のロック中かログイン画面です（まれに、アプリ名が分からないときも括弧なしになります）。ロックを解除すると再開します。解除したあとも出たままなら、どこかのアプリがセキュア入力をオンにしたままです（下の「パスワード欄を離れても続くとき」と同じ。ロックの解除やスリープからの復帰のあとは、macOS がアプリ名を教えないことがあります）。
  - パスワード欄からほかの欄に移るか、パスワードの画面を閉じると再開します。
  - パスワード欄を離れても続くときは、どこかのアプリが macOS のセキュア入力（ほかのアプリがキーを見られないようにする仕組み）をオンにしたままです。古い Chrome や Electron のアプリ、パスワード管理アプリで起きることがあります。このとき括弧の中は、セキュア入力がオンになったときに前面にあったアプリの名前で、オンにしたままのアプリとは限りません。3 つの違うアプリに続けて切り替えると（例: A → B → C。A と B を行き来するだけでは再開しません）、Plamonic はオンにしたままと見なして読み取りを再開します。セキュア入力そのものを止めるには、心当たりのアプリを終了してください。
  - Terminal を「オフ」にしていて、Terminal の「セキュアキーボード入力」がオンのときは、Terminal が前面にある間は止まります。Terminal のメニューでセキュアキーボード入力をオフにするか、Terminal を「自動」か「手動」にしてください。「自動」か「手動」でも、セキュアキーボード入力がオンなら、検索欄にフォーカスがある間は止まります（画面に戻ると再開します）。
  - ターミナルで「<アプリ名> がパスワードを待っているため、このウインドウの読み取りを止めています」と出ているときは、そのウインドウだけを止めています。画面に何か出力されると再開します。最後の行が「password」を含み「:」で終わる文章のときも、パスワードを待っていると見なします。
  - 「一般」の「パスワード入力中は読み取らない」をオフにすると、パスワードの入力中も読み取ります（パスワード欄の中身は、オフでも読み取りません）。
- **ホットキーが効かない**
  ほかのアプリが同じ組み合わせを使っていると登録できません。メニューにエラーが表示されるので、「ホットキー」で別の組み合わせにしてください。
- **ログを見たい**
  「コンソール」アプリでサブシステム `io.smdr.Plamonic` を絞り込んでください。
